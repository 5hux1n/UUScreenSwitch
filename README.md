# UU远控切屏

UU远程 iOS 插件。支持 iOS 15.0 及以上。

- 把默认控制菜单里的展开全部窗口和显示桌面替换为直接切换显示器，适合双显示器用户。
- 在底部控制栏点击「显示器1」「显示器2」即可直接切换对应屏幕，无需进入多层菜单。

## 安装与下载

当前版本：**1.0.0**

- [下载 1.0.0](https://github.com/5hux1n/UUScreenSwitch/releases/tag/v1.0.0)
- 插件源：`https://apt.mjh.im`

| 安装环境 | 下载 |
|---|---|
| Rootless | [Rootless 版](https://github.com/5hux1n/UUScreenSwitch/releases/download/v1.0.0/UUScreenSwitch_1.0.0_arm64.deb) |
| RootHide | [RootHide 版](https://github.com/5hux1n/UUScreenSwitch/releases/download/v1.0.0/UUScreenSwitch_1.0.0_arm64e.deb) |

按越狱环境选择安装包。巨魔注入使用 Rootless 包，由注入工具加载包内插件。
